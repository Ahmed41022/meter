# Screenshots

Four images, referenced from the root `README.md`. Capture them at a window
width of about **900px** on a light background, then delete the comment
markers around the screenshot table in `README.md`.

| File | What to capture |
| --- | --- |
| `overview.png` | The **Overview** tab on a period with real data — the headline figure, the by-project bars and the activity calendar all visible. |
| `running.png` | A session **running**, so the meter face is green and the money is mid-accrual. |
| `project.png` | One project open, showing its ledger of sessions with tasks and rates. |
| `phone.png` | Meter installed on Android, in standalone mode with no address bar. |

Keep them under about 400 KB each. PNG, not JPEG — the UI is flat colour and
text, which JPEG smears.
